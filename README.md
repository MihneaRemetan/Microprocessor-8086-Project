This project implements a microsystem based on the Intel 8086 microprocessor, developed for educational purposes.

The system includes a complete Central Processing Unit built around the Intel 8086, together with EPROM and SRAM memories, serial and parallel interfaces using the 8251 USART and 8255 PPI, a matrix keypad, LEDs, and a 6-digit multiplexed 7-segment display. All hardware components are connected and simulated in EasyEDA, using dedicated address decoding, while all functionalities are implemented using modular 8086 assembly subroutines.

Main features:
- Central Processing Unit based on the Intel 8086
- Memory interfacing with EPROM 27C2048 and SRAM 62512
- Serial communication via 8251 USART
- Parallel communication via 8255 PPI
- Programmable timing using the 8253 timer
- Matrix keypad scanning (4×3)
- LED control and 6-digit 7-segment display multiplexing

Note: The documentation and other additional comments are in Romanian, but the logic is easy to follow regardless of language.
